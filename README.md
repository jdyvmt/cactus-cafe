# 🌵 Cactus Café

Een flexijob salaris tracker webapp. Registreer je werkuren en laat de app automatisch berekenen hoeveel je hebt verdiend met inachtneming van toeslagen en vergoedingen.

## Functies

✅ **Werkdagen Registreren**
- Log start- en eindtijd per werkdag
- Voeg notities toe
- Verwijder entries indien nodig

✅ **Automatische Loonberekening**
- Berekening op basis van instelbaar uurloon
- Nachtwerk toeslagen (% op bepaalde uren)
- Zondagwerk toeslagen
- Overige toeslagen (volledig instelbaar)
- Fietsvergoeding per dag

✅ **Dashboard**
- Totale verdiensten deze maand
- Aantal werkdagen
- Gemiddelde verdiensten per dag
- Grafische weergave
- Vergelijking met vorige maand

✅ **Rapportage**
- Gedetailleerde rapportage per maand
- Vergelijking met dezelfde maand vorig jaar
- Tabeloverzicht met alle gegevens

✅ **Instellingen**
- Stel je uurloon in
- Maak eigen toeslagen aan
- Definieer op welke dagen/uren toeslagen gelden
- Fietsvergoeding instellen

## Hoe Gebruiken

### 1. Werkdag Inloggen
1. Ga naar het tabblad "📝 Werkdagen"
2. Selecteer de datum
3. Vul start- en eindtijd in
4. Optioneel: voeg notities toe
5. Klik op "Opslaan"

### 2. Instellingen Configureren
1. Ga naar het tabblad "⚙️ Instellingen"
2. Vul je uurloon in
3. Vul fietsvergoeding in (optioneel)
4. Voeg toeslagen toe:
   - Geef de toeslag een naam (bijv. "Nachtwerk")
   - Vul het percentage in
   - Optioneel: definieer de uren waarop het geldt
   - Selecteer de dagen waarop het geldt
5. Klik "Instellingen Opslaan"

### 3. Dashboard Bekijken
1. Ga naar het tabblad "📊 Dashboard"
2. Bekijk je verdiensten van deze maand
3. Zie de grafische weergave
4. Vergelijk met vorige maand

### 4. Rapportage Genereren
1. Ga naar het tabblad "📈 Rapportage"
2. Selecteer een maand
3. Klik "Genereer Rapport"
4. Bekijk gedetailleerde rapportage en vergelijking

## Gegevens

- Alle gegevens worden **lokaal in je browser** opgeslagen (localStorage)
- Geen gegevens worden naar servers gestuurd
- Je gegevens blijven privé op jouw apparaat
